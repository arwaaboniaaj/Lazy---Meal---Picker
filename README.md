# Lazy---Meal---Picker
 ## Project Description


This project is a meal planning web application in Java. The application provides a simple web interface to browse and explore different meals.

The application uses the built-in HTTP server of Java to serve HTML pages and to process requests. No database is needed for storing meal data in memory with the help of java arrays.

The project shows:

* Java back-end development
*Frontend HTML/CSS integration
*Handling HTTP Requests
 *Dynamic content creation

--- 

## Features 
* Search meals by category
* See meal details
* User-friendly and easy interface
* Lightweight server installation
* No database is required

---
### Technologies used
* Java 
* HTML 
* Cascading Style Sheets ( CSS )
* Java HTTP Server (com.sun.net.httpserver.HttpServer)
Java Script

## Running the project

1. Open the project in VS Code/ IntelliJ Idea.

2. Compile and run the Java application.
bash
javac Main.java
java Main

3. Launch your browser and go to:
bash
http://localhost:8000

--- 

## Data Base

In this project, we did not use any database.

During run-time the meal data are stored directly in Java arrays.
